# Week 3 Database Assignment

## Introduction
This assignment practices basic SQL data definition and data manipulation using MySQL.

## Objectives
- Create a student table with a primary key.
- Insert at least three student records.
- Update a student's age using an SQL UPDATE statement.
- Verify the changes using SELECT.

## Table Structure
The `student` table contains:
- `id`: Integer primary key.
- `fullName`: Name of the student, up to 100 characters.
- `age`: Integer representing the student's age.

## Questions Completed
1. Created the `student` table.
2. Inserted three student records.
3. Updated the age of the student with ID 2 to 20.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## How to Run
1. Connect to your MySQL server using MySQL Workbench.
2. Select the database you intend to use.
3. Open `week3_assignment.sql`.
4. Execute the SQL statements.
5. Run `SELECT * FROM student;` to verify the records.

## Conclusion
This assignment provided practical experience with creating tables, inserting records, and updating data using SQL.
